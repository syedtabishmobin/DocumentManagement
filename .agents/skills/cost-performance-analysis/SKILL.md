# Cost and performance analysis

1. Run `pnpm agent:summary` for the relevant evidence window and retain provenance with every usage or cost statement.
2. Compare cost/usage with accepted outcomes, first-pass QA, rework, defects, retries and duration; never optimise a metric in isolation.
3. Identify redundant discovery, repeat context loading, unnecessary skills/subagents/tools, retry loops, or model/profile mismatch only where evidence exists.
4. Recommend the smallest reversible change that preserves quality, security, privacy, accessibility and reliability gates.
5. Route material model, provider, retention, routing or governance changes through the normal decision protocol before applying them.
