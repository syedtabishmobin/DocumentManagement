# Doculyra build baselines

This folder preserves versioned, governed build baselines. A baseline is a controlled implementation reference, not permanent immutability and not evidence that the product or any goal is complete.

Material changes to vision, outcomes, success measures, features, stories, acceptance criteria, architecture, security/privacy, data/domain, AI evaluation, or UX journeys require a new baseline version with impact and review evidence. Routine implementation detail may evolve inside the approved contracts.

The machine-readable current candidate is [`../build-baseline.v1.json`](../build-baseline.v1.json). Historical baseline records remain available and IDs are never recycled.
